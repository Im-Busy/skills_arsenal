# Synthesis Format — Convergence / Tension / Blind Spot / Actions

Phase 4 (SYNTHESIZE) produces a unified synthesis across all insights and connections gathered in prior phases. Output has exactly **4 sections**. ALL 4 MUST be populated — empty sections mean the phase gate fails.

---

## Points of Convergence

Identify where independent insights triangulate on the same finding. Each convergence point must be backed by at least two distinct insights from the insight registry.

### Template

```markdown
## Points of Convergence

### [Theme Name]
**Finding:** [Synthesized finding — what multiple independent insights point to]
**Supporting Insights:** [insight_001, insight_007]
**Strength of Convergence:** [Strong / Moderate / Tentative]
**Explanation:** [2-4 sentences explaining convergence and significance]
```

### Requirements

- **Minimum:** ≥1 convergence point
- **Evidence:** Each convergence backed by ≥2 independent insights
- **Rating:** Rate convergence strength:
  - **Strong** — triangulated finding with high confidence (same conclusion from ≥3 sources with different methodologies)
  - **Moderate** — corroborated but not fully triangulated (2-3 sources, possibly same approach)
  - **Tentative** — suggestive but weak (only 2 sources or conflicting methodology)
- **Explanation:** Must articulate WHY the convergence matters, not just that it exists

---

## Core Tension

Surface genuine conflicts between insights. The tension itself is often more valuable than either position — it reveals where the evidence is genuinely unsettled.

### Template

```markdown
## Core Tension

### [Tension Name]
**Position A:** [What some evidence suggests — cited]
**Position B:** [What conflicting evidence suggests — cited]
**Resolution Possibility:** [How to resolve — specific, not "more research needed"]
**Significance:** [Why this tension MATTERS — this IS often the most valuable insight]
```

### Requirements

- **Minimum:** ≥1 substantive tension
- **No-conflict gate:** If the Council determines no tensions exist, this must be explicitly confirmed with a consensus note. Do not fabricate a tension.
- **Citations:** Each position cites specific insight IDs
- **Resolution:** Must propose a resolvable path (specific experiment, decision rule, or tie-breaker). "More research needed" is NOT an acceptable resolution.
- **Tension-first mindset:** A well-framed tension is often more useful than either position in isolation — it shows where the design space is genuinely contested.

---

## The Blind Spot

Identify what NO source addressed. This is NOT about a source being weak on a topic — it's about a gap across ALL sources.

### Template

```markdown
## The Blind Spot

### [Blind Spot Name]
**What's Missing:** [What NO source addressed — not "source X was weak on Y"]
**Why It Matters:** [Why this gap is significant for conclusions]
**Impact on Conclusions:** [How this gap affects confidence in synthesis]
```

### Requirements

- **Minimum:** ≥1 blind spot
- **Genuine gap:** Must be genuinely unaddressed by ALL sources (not just poorly covered)
- **Not a source critique:** Phrasing like "None of the sources tested X under Y conditions" is correct. Phrasing like "Source A was weak on X" is incorrect — that is a source weakness, not a blind spot.
- **Practical impact:** Explain the consequence: "We can't conclude X because no source tested Y."

---

## Recommended Actions

Translate the synthesis into concrete next steps. Every action must be specific enough that a new agent could execute it.

### Template

```markdown
## Recommended Actions

| Priority | Action | Supporting Insights | Feasibility | Impact |
|----------|--------|---------------------|-------------|--------|
| 1 | [Concrete action] | [insight_001, insight_003] | High | High |
| 2 | [Concrete action] | [insight_007] | Medium | High |
| 3 | [Concrete action] | [insight_002, insight_005] | Low | Medium |
```

### Requirements

- **Minimum:** ≥3 actions
- **Citations:** Each action cites specific insight IDs that support it
- **Ratings:** Feasibility and Impact each rated **High** / **Medium** / **Low**
- **Priority ordering:** Priority 1 = do this first. Higher impact + higher feasibility ranks first.
- **Concrete test:** An action is concrete if you could assign it to a new agent without further clarification. "Implement X using pattern Y" passes. "Consider X" fails.
- **Broken actions:** If an action has Low feasibility, it must still be worth knowing about (it may become feasible later, or someone else may solve the dependency).

---

## Quality Checklist

Run this checklist before declaring synthesis complete.

```
- [ ] All 4 sections have ≥2 substantive sentences each
- [ ] Every convergence point cites ≥2 distinct insights
- [ ] Core tension is substantive (not "no tensions found" without Council confirmation)
- [ ] Blind spot is a genuine gap (not a weakness of a single source)
- [ ] ≥3 recommended actions, each with cited insights
- [ ] Every claim has a traceable insight ID
- [ ] Actions are concrete and ordered by priority
```
